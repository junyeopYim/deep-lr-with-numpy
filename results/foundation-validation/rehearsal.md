# 독립 실행 점검 — 2026-09-12

이 문서는 첫 00·01 재설계의 점검 기록입니다. 이후 공통 기초 00–04 전체 결과는 [공통 기초 검증](common-foundations.md)에 있습니다.

**관찰됨: 두 차례의 독립 실행을 거쳐, 수정된 자료에서 실행을 막는 지점 0건을 확인했습니다.**
제작 대화를 읽지 않은 새 executor가 각 차례를 수행했습니다.
사용자의 학습 목표와 자료에 명시한 준비물을 기준으로 README → 학습 설계 → 두 노트북을 따라갔습니다.
이 결과는 자료의 실행 가능성에 관한 기록이며, 실제 사용자의 이해 향상을 측정한 결과는 아닙니다.

## 발견과 반영

| 1차 발견 | 자료 수정 | 2차에서 직접 확인한 것 |
|---|---|---|
| `history[0]` 설명을 따라 조회하면 `KeyError` | loss·W·b 딕셔너리 키를 명시 | 0·1·5·200회 기록 조회, 같은 파라미터로 손실 재계산 |
| Jupyter 서버 루트가 노트북 폴더로 제한돼 상위 자료가 HTTP 404 | 첫 명령에 `--ServerApp.root_dir=.` 추가 | 노트북·문서·보조 코드가 HTTP 200으로 제공됨 |
| Python 준비물만으로 셀 실행·추가 방법을 알기 어려움 | README에 실행·셀 추가·함수 전달·재시작 방법 추가 | 직접 함수 작성 후 두 검사 함수에 전달하여 통과 |
| 격자 계산의 중간 shape와 축 설명 부족 | 00·01 해당 절에 배열 shape 표와 인덱싱 설명 추가 | 평면의 한 점, 손실 지형의 한 후보를 따로 계산해 일치 확인 |
| 검산 콜백의 `dout` 설명 부족 | `G=uJ`의 미분과 상류 기울기를 설명 | 직접 고른 u=-0.75에서 중심차분 `0.062936492989…`와 `u*dW=0.062936493001…` 일치 |

첫 서버 명령의 실패와 수정 명령의 성공은 [수정 전](rehearsal/round1/jupyter-start.json),
[수정 후](rehearsal/round1/jupyter-start-fixed-command.json) 기록으로 비교할 수 있습니다.
1차 입력 사본의 상태는 [파일 해시](rehearsal/round1/snapshot-sha256.json)에 남겼습니다.

## 확인 범위

Jupyter GUI를 조작할 브라우저·컴퓨터 사용 도구가 없어 단축키·메뉴 클릭과 노트북 내부 링크를
실제로 클릭하는 동작은 확인하지 못했습니다. 서버의 파일 제공, 새 커널 실행, PNG 디코딩·시각 확인을
각각 수행했습니다. 단축키·명령 이름은 README에 연결한 공식 문서로 확인했습니다.

독립 실행기의 TCP 관련 시작 경고와 자동 브라우저 열기 실패는 실행 환경의 메시지였습니다.
노트북 셀의 실행 오류·한글 글리프 경고는 없었습니다. 저장소의 최종 검증 스크립트는 POSIX에서 IPC를 사용합니다.
실제 학습에서 설명의 깊이와 속도가 적절한지는 사용자의 학습 반응에 따라 조정합니다.
