# deep-learning-from-scratch 프로젝트 기억

대화에서 확정한 방향과 실행 상태를 두 도구가 공유합니다.

| 파일 | 내용 | 기록 방식 |
|---|---|---|
| `DECISIONS.md` | 사용자가 확정한 결정 | 추가 전용 |
| `OPEN-QUESTIONS.md` | 미정 범위와 제안 | 확정 결정과 구분 |
| `SESSION-LOG.md` | 세션별 작업 기록 | 날짜별 추가 |
| `CHECKPOINT.md` | 현재 상태와 바로 할 다음 행동 | 이전 버전 보존 후 갱신 |
| `checkpoints/` | 이전 체크포인트 | 추가 전용 |
| `HANDOFF.md` | 다음 세션에 넘기는 지시. 읽은 세션이 바로 삭제 | 단발성 |
| `goal/` | 현재 작업의 구조와 검증 근거 | 변경 이력 보존 |

학습 계획의 본문은 `../docs/CURRICULUM.md`, 학습 내용과 관측 결과는 노트북에 둡니다.
