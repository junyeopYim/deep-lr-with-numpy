# 기호와 배열의 대응

[00번 노트북](../../notebooks/00_기초/00_math_to_numpy.ipynb)과
[01번 노트북](../../notebooks/00_기초/01_gradients_and_learning.ipynb)에서 사용하는 표기입니다.

## 입력·출력·파라미터

| 기호 | 모양 | 뜻 |
|---|---|---|
| $N$ | 정수 | 샘플 수 |
| $D$ | 정수 | 입력 특성 수 |
| $K$ | 정수 | 출력 수 |
| $X$ | `(N, D)` | 샘플을 행으로 모은 입력 |
| $W$ | `(D, K)` | 입력에서 출력으로 연결하는 가중치 |
| $b$ | `(K,)` | 출력마다 더하는 편향 |
| $Z=XW+b$ | `(N, K)` | 예측값 |
| $Y$ | `(N, K)` | 회귀 문제의 정답 |
| $J$ | 스칼라 | 모든 출력의 오차를 모은 손실 |

인덱스와 합으로 쓰면 다음과 같습니다.

$$Z_{nk}=\sum_{d=0}^{D-1}X_{nd}W_{dk}+b_k.$$

샘플 $n$과 출력 $k$는 남고, 입력 특성 $d$를 곱해서 더합니다.
그 관계가 `X @ W`의 두 안쪽 차원이 일치하는 이유입니다.

## 미분 배열

`dZ`는 $\partial J/\partial Z_{nk}$를 원래 $Z$와 같은 모양으로 모은 배열입니다.
스칼라 손실에 대한 편미분을 배열마다 모으므로 `dW.shape == W.shape`처럼 대응합니다.

$$dW=X^\top dZ,\qquad db=\sum_n dZ_n,\qquad dX=dZ W^\top.$$

- 가중치는 샘플마다 공유하므로 `dW`는 각 샘플의 기여를 합합니다.
- 편향도 모든 샘플에 쓰이므로 `db = dZ.sum(axis=0)`입니다.
- 입력 하나는 여러 출력에 영향을 주므로 `dX`는 출력별 기여를 합합니다.

## 손실의 평균 축

01번은 다음 목적을 사용합니다.

$$J=\frac1{2NK}\sum_{n,k}(Z_{nk}-Y_{nk})^2.$$

따라서 `dZ = (Z - Y) / (N * K)`이며 코드에서는 `(Z - Y) / Z.size`입니다.
이 평균은 `dZ`에 들어 있습니다. 그 뒤의 `dW`·`db`는 위의 합으로 계산합니다.
각 손실을 만들 때 **평균을 내는 축과 그 분모**를 함께 적습니다.

## 이후 역전파로의 연결

배열을 긴 벡터로 펼쳤다고 생각하면, 함수의 모든 편미분을 모은 것이 Jacobian입니다.
벡터를 열로 두는 표기에서는 `backward(dout) = Jacobian.T @ dout`입니다.
실제 구현에서는 이 곱을 정리한 `dZ @ W.T` 등의 식을 직접 계산합니다.
