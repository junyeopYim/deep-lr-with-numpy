# 이 프로젝트의 학습 방식

사용자가 2026-09-12에 설명한 목표와 선호를 바탕으로 구성했습니다.

> 알고 있는 개념을 수학으로 구성하고, 그 수학을 코드로 옮기는 학습이 필요합니다.

수학 설명은 **행렬·미분·확률도 코드와 함께 다시 확인하는 지점**에서 시작합니다.
실습은 **작은 완성 예제를 이해한 뒤 직접 바꾸는 문제를 푸는 방식**입니다.

## 한 개념에서 연결할 것

| 단계 | 할 일 | 예: 선형 회귀 |
|---|---|---|
| 문제 | 입력·정답·예측의 의미 정하기 | 숫자 입력으로 관측값 예측하기 |
| 목적 | 무엇이 좋아져야 하는지 수식으로 정하기 | 잔차의 제곱을 평균내기 |
| 수학 | 기호와 변화율 유도하기 | 예측 `XW+b`, 손실, `dW`·`db` |
| 배열 | shape와 합하는 축 정하기 | `(N,D) @ (D,K) → (N,K)` |
| 코드 | 손계산 → 반복문 → 벡터화 | 작은 숫자로 같은 계산 세 번 확인 |
| 검산 | 독립된 방법으로 대조하기 | 중심차분, 최소제곱 해 |
| 변형 | 스스로 바꾸고 결과 설명하기 | 출력 개수·계수·학습률 바꾸기 |

수학의 정의는 실제로 쓰이는 자리에서 소개합니다. 예를 들어 미분은 파라미터를 어떻게 움직일지
설명할 때, 확률과 우도는 손실을 왜 그렇게 정하는지 설명할 때 연결합니다.

## 노트북 안에서 공부하는 순서

1. **예상:** 설명을 읽고 출력값·모양·변화 방향을 먼저 적습니다.
2. **완성 예제:** 작은 문제의 수식과 코드를 함께 읽고 실행합니다.
3. **검산:** 손계산, 다른 구현, 수치미분 중 해당 계산에 맞는 기준과 비교합니다.
4. **변형:** 입력·차원·연결·목적을 한 가지씩 바꿉니다.
5. **복원:** 예제 셀을 가리고 핵심 함수와 미분을 다시 작성합니다.
6. **되짚기:** 준비도 질문 중 막힌 항목의 설명과 작은 예제로 돌아갑니다.

검산 코드도 노트북 본문에 있습니다. 직접 작성한 함수를 검사 함수에 전달하여 확인할 수 있습니다.
그림의 입력 좌표·은닉 상태·예측·도함수·손실은 본문에서 계산하고, 보조 파일은 결과의 배치를 맡습니다.

## 이해를 확인하는 네 단계

한 주제를 공부한 다음 네 항목을 따로 확인합니다.

| 상태 | 자신에게 할 질문 |
|---|---|
| 설명 가능 | 입력·출력·목표와 이 계산이 필요한 이유를 말할 수 있나요? |
| 수식 구성 가능 | 기호의 의미와 합하는 축, 목적과 미분을 쓸 수 있나요? |
| 직접 구현 가능 | 수식을 보고 NumPy 함수를 다시 작성할 수 있나요? |
| 변형 검산 가능 | 차원이나 목적이 바뀌었을 때 코드를 바꾸고 결과를 확인할 수 있나요? |

이는 사용자의 현재 실력을 미리 판정한 기준이 아니라, 다음 복습 지점을 찾는 기준입니다.
실제로 공부하면서 막히는 지점에 따라 설명량과 문제 난도를 조정합니다.

## 주제들을 연결해서 보는 방법

각 모델을 다음 네 질문으로 정리합니다.

- **구조:** 입력에서 출력까지 어떤 계산을 하나요?
- **목적:** 어떤 출력이 좋은 출력이며, 그 기준은 어떻게 수식이 되나요?
- **학습:** 어떤 데이터에서 기울기를 계산하고 어떤 상태로 파라미터를 갱신하나요?
- **사용:** 학습한 뒤 예측·복원·생성·행동 선택을 어떻게 수행하나요?

예를 들어 VAE에서는 잠재변수·변분 목적·재매개화를, GAN에서는 두 모델의 목적과 교대 갱신을
연결해서 공부합니다. 두 연구 모두 구조와 목적, 학습 과정을 함께 다루는 예시입니다.
[Kingma·Welling의 VAE 논문](https://arxiv.org/abs/1312.6114),
[Goodfellow 외의 GAN 논문](https://arxiv.org/abs/1406.2661).

전체 단위와 전제는 [커리큘럼](CURRICULUM.md)에 있습니다.

## 한 단원을 공부할 때의 깊이

| 읽는 순서 | 실제로 남길 것 | 다음 행동 |
|---|---|---|
| 완성 예제 | 문제·입력·출력과 예상 결과 | 작은 숫자로 같은 계산을 실행 |
| 수식 복원 | 가정·shape·평균 축·기울기 경로 | 핵심 함수를 새 셀에 다시 작성 |
| 독립 검산 | 손계산·중심차분·다른 분해의 비교 | 자신의 함수를 검사기에 전달 |
| 직접 변형 | 바꾼 조건과 변화 이유 | 실제 학습/생성/평가 loop에 자신의 함수 연결 |

예를 들어 11은 SVD와 공분산 고유분해로 같은 부분공간을 찾고, 13은 같은 MLP를
직접 backward·작은 엔진·PyTorch로 계산합니다. 14는 출력 개수를 바꾸어 평균 축을 확인하고,
15는 평가할 사례의 단위를 바꾸어 같은 점수의 의미를 확인합니다.

현재 실행 자료는 00–15입니다. 이후 경로에서도 이 순서를 적용하며,
하나의 모델을 구조·목적·갱신·사용으로 나눈 다음 작은 완성 예제를 만듭니다.

## 구성의 근거와 조정 방법

풀이된 예제와 직접 해결하는 문제를 번갈아 배치하고, 추상적인 설명을 구체적인 표현과 연결하는
구성을 설계의 근거로 삼았습니다.
[IES의 학습·수업 구성 가이드](https://ies.ed.gov/ncee/wwc/PracticeGuide/1).

예제 셀을 가리고 수식과 코드를 다시 작성하는 활동도 넣었습니다. 기억에서 내용을 꺼내는 연습을
다룬 연구를 참고한 설계 선택입니다.
[Roediger·Karpicke의 연구](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2006.01693.x/).

이 자료들은 활동 구성의 근거입니다. 이 사용자에게 맞는 설명의 깊이와 속도는
실제 학습 반응으로 확인하고 조정합니다. 파일의 실행 검증은 코드와 자료의 사용 가능성을 확인합니다.
